# Calorie Tracker

This app allow user register calories  consumed and burnend 

the app works to the next way: 
- The user adds the food and its calories 
- The user adds exercises or activities along with the number of calories burned.

## Results

The app going to show the calories consummed, the calories burned and the difference between them
